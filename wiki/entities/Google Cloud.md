# Google Cloud

## Core
Google Cloud (Google Cloud Platform) is Google's cloud computing division. In this
vault it appears as the publisher of the [[Open Knowledge Format]] specification and
reference tooling.

## Key Points
- Publishes the [[Open Knowledge Format]] (OKF) repository and v0.2 spec.
- Ships a proof-of-concept OKF-producing agent and a graph visualizer.
- References its own data products (e.g. BigQuery public datasets) in OKF example
  bundles.

## Details
The OKF project is released under the GoogleCloudPlatform GitHub organization. The
example bundles draw on Google Cloud data sources such as the GA4 e-commerce and
BigQuery public datasets (Stack Overflow, Bitcoin), using `gcloud` auth for access.
