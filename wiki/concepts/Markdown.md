# Markdown

## Core
Markdown is a lightweight plain-text formatting syntax. In this vault it is the shared
substrate for both the [[Open Knowledge Format]] and the [[Persistent Wiki]] pattern —
knowledge is stored as plain markdown files rather than in a proprietary store.

## Key Points
- Human- and agent-readable; no SDK or query layer between reader and content.
- Plays well with version control and existing tools like [[Obsidian]].
- Pairs with [[YAML Frontmatter]] to mix structured and unstructured data.
