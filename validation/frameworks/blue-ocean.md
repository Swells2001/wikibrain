# Framework 2: Blue Ocean Strategy

Run Blue Ocean Strategy on the project in `validation/project.md`.

## Steps

1. List the 3 to 5 alternatives a user has today, including doing nothing.
2. List 4 to 6 factors people compare those alternatives on.
3. Build the ERRC grid: Eliminate, Reduce, Raise, Create. Put at least one item in each box.
4. State in one sentence where the project is uncontested and why a user would switch.

## Output format

- The alternatives and the factors, as short lists.
- The ERRC grid as a Markdown table:

| Eliminate | Reduce | Raise | Create |
|---|---|---|---|
| ... | ... | ... | ... |

- One line: `Value innovation:` followed by the one-sentence statement.

## Rules

- **Red-ocean rule:** if the answer is "we are just better", say that this is a red ocean, and say what would have to be true to find a blue one.
- Cite evidence from `project.md` for every item, or say "no evidence yet".
- Tag each item as [real person], [desk research], [AI opinion], or [no evidence yet].
- Keep the whole output under 300 words.
