# Framework 5: MoSCoW

Run MoSCoW prioritization on the project in `validation/project.md`.

Take the features listed under "My solution" in `project.md` and sort them into four lists:

- **Must** (this version fails without it)
- **Should** (important, but the version works without it)
- **Could** (nice to have)
- **Won't** (not in this version)

## Output format

Four short lists, then one sentence labeled `Smallest thing that proves it:`

## Rules

- No more than 3 Musts.
- Every Must links to a job in the JTBD output. Name the job next to it.
- The Won't list is not empty.
- Cite evidence from `project.md` for every item, or say "no evidence yet".
- Tag each item as [real person], [desk research], [AI opinion], or [no evidence yet].
- Keep the whole output under 300 words.
